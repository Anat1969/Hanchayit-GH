מדריך דיגיטלי להנחיות המרחביות של אשדוד (מהדורה 18, דצמבר 2024): הנוסח המלא עם חיפוש, לצד מודל תלת מימדי של כל נושא. גרסה 1 מכסה את פרק ב'.

## כתובת האפליקציה

**https://anat1969.github.io/Hanchayit-GH/**

| קובץ | תוכן |
