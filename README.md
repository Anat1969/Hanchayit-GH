# הנחיות מרחביות אשדוד – מדריך תלת מימדי

מדריך דיגיטלי להנחיות המרחביות של אשדוד (מהדורה 18, דצמבר 2024): הנוסח המלא עם חיפוש, לצד מודל תלת מימדי של כל נושא. המדריך מכסה את פרק א' (עבודות פטורות מהיתר) ואת פרק ב' (עבודות הטעונות היתר).

## כתובת האפליקציה

**https://anat1969.github.io/Hanchayit-GH/**

כל דחיפה לענף הראשי מריצה בדיקות, בונה ומפרסמת את האתר (`.github/workflows/deploy.yml`).
הפעלה חד־פעמית: Settings ← Pages ← Source: GitHub Actions.

כתובת קבועה לכל סעיף: `/rule/<מזהה>`, למשל https://anat1969.github.io/Hanchayit-GH/rule/B2.7.1-6

## מצב

- שלב 1 (שלד, נתונים וחיפוש): גמור. 146 הסעיפים מוצגים, החיפוש בעברית עובר את הבדיקות והנתונים עוברים ולידציה.
- שלב 2 (מנוע סצנות וחמש סצנות): גמור. גדר לרחוב, קיר תמך מדורג, מצללה על הקרקע, מרחק בין בניינים וגובה קומת קרקע, בתכנית, חתך ואקסונומטריה. כל מידה במודל נקראת מהנתונים ומקושרת לנוסח בשני הכיוונים.
- שלב 3 (שאר הסצנות): גמור. כל 24 הסצנות, כולל חישוב צל לפי מיקום השמש באשדוד ב־21 ביוני ודיאגרמת שטחים מתוך טבלת 2.3.6.
- שלב 4 (מצב בחינה): גמור. מתג בתחתית העמוד, מחוון ליד כל ערך, השוואה "מקורי ← נבחן" בנוסח ובמודל, הערות בדיקה וייצוא השינויים ל־CSV.
- שלב 5 (פרק א'): גמור. 279 סעיפים חולצו מה־PDF, עם 87 פרמטרים ו־7 סצנות: גדר וקיר תומך, גגון וסוכך, סככת צל לחניה, מצללה, מחסן, כבש נגישות ומתקנים על הגג. חיפוש לפי מספר סעיף מקבל אות פרק ("א 3.2.4").

## פיתוח

```
npm install
npm run dev        # שרת פיתוח
npm run test       # בדיקות
npm run validate   # ולידציה של data/*.json
npm run build      # בנייה ל־dist/
npm run screenshots  # צילומי מסך של הסצנות (דורש npx vite preview --port 4173)
```

## מסמכים

| קובץ | תוכן |
|---|---|
| `CLAUDE.md` | הנחיות עבודה לבניית האפליקציה: עקרונות, סטאק, מבנה, פקודות |
| `docs/SPEC.md` | אפיון: מסכים, חיפוש, סצנות, שלבים ותנאי סיום לכל שלב |
| `docs/DESIGN.md` | השפה העיצובית המחייבת, כולל רשימת האסור |
| `docs/DATA-MODEL.md` | מבנה הנתונים |
| `data/chapter-a.json` | פרק א' כנתונים (חולץ מה־PDF, ראו review-notes) |
| `data/chapter-b.json` | פרק ב' כנתונים |
| `data/synonyms.json` | מילים נרדפות לחיפוש |
| `data/review-notes.md` | עמימויות ידועות בהנחיות, לבחינת צוות אדריכלית העיר |
